# INNISFREE KV Studio

월간 캠페인 히어로를 확정된 제품 사진과 박스 도면으로 구성하는 로컬 스튜디오입니다. 화면은 한국어입니다.

이미지 모델이 구색을 다시 그리지 않습니다. 수량, 박스 mm, 아트워크 위치, 비율, 레이어, 출력 크기는 앱이 정하고, 최종 이미지는 올린 제품과 확정한 박스 면으로 합성합니다. 원본 파일은 바꾸지 않고, 자르기와 배치만 따로 저장합니다.

## 작업 흐름

1. 프로젝트를 만들고 출력 크기를 정합니다.
2. 제품 PNG와 박스 PDF를 올립니다. Illustrator `.ai`는 읽지 않습니다. PDF로 보낸 뒤 올리세요.
3. PDF에서 앞면, 옆면, 윗면을 지정하고 가로·세로·깊이 mm를 입력합니다. 지정하지 않은 면은 미확인으로 남습니다.
4. 세트와 구색 수량을 등록합니다. 같은 샘플 3개는 장면 인스턴스 3개입니다.
5. 구색 기준으로 배치한 뒤, 캔버스나 수치로 위치와 균일 크기를 조정합니다.
6. 배경은 직접 올리거나, 키가 있을 때만 환경 이미지만 생성합니다.
7. 한국어 수정 문장으로 배경 밝기, 세트 위치, 샘플 간격, 받침대, 위쪽 여백만 바꿉니다.
8. 구성을 검증하고 PNG, JPG, 배경, 제품, 그림자, 복원용 패키지를 내보냅니다.

데모 열기는 승인된 이니스프리 아트워크가 아닙니다. 화면과 파일에 그 사실이 표시됩니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
cp .env.example .env
npm run dev
```

브라우저는 http://127.0.0.1:5173 , API는 http://127.0.0.1:8787 입니다. 데이터와 원본 파일은 `DATA_DIR`(기본 `./data`)에 저장됩니다.

```bash
npm test
npm run typecheck
npm run build
npm start
```

`npm start`는 API만 띄웁니다. `npm run build` 이후에는 같은 서버가 `dist/client`도 제공합니다.

## 환경 변수

| 변수 | 필요할 때 |
| --- | --- |
| `OPENAI_API_KEY` | 패키지 분석, 콘셉트 제안, 배경 생성, 시각 리뷰, 예시 문장 밖의 수정 해석 |
| `OPENAI_VISION_MODEL` | 분석과 시각 리뷰. 기본 `gpt-6.2-astra` |
| `OPENAI_PLANNING_MODEL` | 콘셉트와 수정 해석. 기본 `gpt-6.2-astra` |
| `OPENAI_IMAGE_MODEL` | 배경 생성. 기본 `gpt-image-2.5-sunburst` |
| `OPENAI_IMAGE_QUALITY` | 배경 품질. 기본 `medium` |
| `PORT` | API 포트. 기본 `8787` |
| `DATA_DIR` | SQLite와 자산 디렉터리. 기본 `./data` |

키가 없으면 해당 요청은 `503 ai_not_configured`를 반환하고 성공한 것처럼 결과를 만들지 않습니다. 수동 배치, 배경 업로드, 다섯 가지 예시 문장, 검증, 내보내기는 키 없이 동작합니다.

예시 문장은 다음입니다.

- 제품 배치는 유지하고 배경만 조금 밝게
- 그린티 세트를 중앙으로
- 블랙티 샘플 간격만 넓혀 줘
- 받침대는 낮추고 위쪽 여백은 늘려 줘
- 제품 크기는 유지해 줘

## 검증

2026-11-23, Node v22.23.4에서 `npx tsc --noEmit`과 `npx vitest run`을 실행했습니다. 테스트 파일 2개, 테스트 10개가 모두 통과했습니다.

- 구색 수량과 같은 수의 인스턴스만 만들고 초과분은 버립니다.
- 알 수 없는 인스턴스와 초과 수량을 검증이 거절합니다.
- 제품 비율과 박스 면 비율을 유지합니다.
- 출력 크기가 달라도 상대 좌표는 같습니다.
- 다섯 가지 수정 문장은 요청한 속성만 바꿉니다.
- PDF 면을 90도 돌리면 가로세로와 픽셀 방향이 바뀝니다.
- 프로젝트를 저장한 뒤 다시 엽니다.
- PDF 매핑, 수량, 장면, 배경 교체, 제품 유지, 내보내기, 패키지 복원, 키 없는 AI 거절을 한 흐름으로 확인합니다.
- 데모는 승인 아트워크로 표시되지 않고 분석 결과를 만들지 않습니다.

브라우저에서 데모 프로젝트를 열고, 구색과 미리보기, 배경 업로드, 수정 문장, 구성 검증, PNG 내보내기, PDF 페이지와 3D 박스 미리보기를 확인했습니다. 내보낸 PNG는 1280×720이었습니다.

## 한계

- 히어로 미리보기와 내보내기는 Sharp의 캐비닛 투영입니다. Three.js 미리보기는 매핑용 원근 뷰라서 픽셀이 같지 않습니다.
- 배경 생성 API는 구현되어 있지만 이 환경에 `OPENAI_API_KEY`가 없어 호출하지 않았습니다. 분석, 콘셉트, 시각 리뷰도 같습니다.
- 배경 모델이 프롬프트의 금지 항목을 어길 수 있습니다. 생성된 배경에 제품, 로고, 글자, 받침대가 보이면 쓰지 말고 직접 올린 배경을 사용하세요.
- 모델 출력 크기는 16의 배수로 맞춘 뒤 프로젝트 프레임에 덮습니다. 비율이 다르면 가장자리가 잘립니다.
- 자동 검증은 출판 품질을 보장하지 않습니다. 화면에도 그 문장을 표시합니다.
- PSD 내보내기는 없습니다.
- 한 구색 행의 수량은 24개까지입니다.
- 용량 문자열로 크기를 추정하지 않습니다. 실제 mm가 없으면 임시 크기로 두고 미확정으로 표시합니다.
- 서버의 한글 라벨은 함께 둔 Noto Sans KR을 사용합니다. 글꼴은 SIL Open Font License이며 고지는 `fonts/OFL.txt`에 있습니다.
- 확대가 크거나 배경 해상도가 낮으면 내보내기 전에 경고가 나오고, 확인해야 파일이 내려갑니다.
